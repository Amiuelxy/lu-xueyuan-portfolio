采购与合同异常核验 · 脱敏方法摘录

以下内容摘自本人提供的原始核验工作簿“00_问题清单”工作表，仅保留异常定义与计算步骤。客户、供应商、合同编号、实际金额、命中条数及内部系统标识均不展示。未添加虚构业务数据。

已签合同未创建PAC-主清单

计算口径：【合同签署状态】=[已签署状态]且【合同文件类型】不为PAC的合同，其【[ERP系统] 开放采购订单号】解析出的PAC号均未出现在PAC清单【采购凭证 / 采购单据】中；无有效PAC号也归入主清单。

原表计算步骤：1、在《合同台账》中筛选【合同签署状态】=[已签署状态]且【合同文件类型】不为PAC； 2、将【[ERP系统] 开放采购订单号】拆解为PAC号； 3、将拆解PAC号匹配《PAC清单》【采购凭证 / 采购单据】； 4、若拆解数量=0，或匹配PAC数量=0，则判定为主清单命中。

材料位置：原始问题清单第2行，C:D列。

已签合同未创建PAC-补充内容

计算口径：【合同签署状态】=[已签署状态]且【合同文件类型】不为PAC的合同，其【[ERP系统] 开放采购订单号】解析出多个PAC号，且部分出现在PAC清单、部分未出现。

原表计算步骤：1、沿用01-1筛选范围； 2、统计同一合同拆解出的PAC数量、匹配PAC数量、未匹配PAC数量； 3、若匹配PAC数量>0且未匹配PAC数量>0，则判定为补充命中。

材料位置：原始问题清单第3行，C:D列。

有合同属性PAC未在[合同管理系统]备案

计算口径：【采购凭证类型】=[采购类型编码]的PAC，其【采购凭证 / 采购单据】未出现在合同台账【[ERP系统] 开放采购订单号】解析出的PAC号集合中；不设置期限>=12个月。

原表计算步骤：1、在《PAC清单》中筛选【采购凭证类型】=[采购类型编码]； 2、在《合同台账》中拆解【[ERP系统] 开放采购订单号】形成合同备案PAC号集合； 3、判断PAC【采购凭证 / 采购单据】是否不在合同备案PAC号集合； 4、不在则命中。

材料位置：原始问题清单第4行，C:D列。

合同金额小于PAC金额

计算口径：【合同金额折[统一币种]】<同一合同已匹配PAC的【PAC合计金额_[统一币种]】；一份合同对应多份PAC时，对已匹配PAC金额折[统一币种]后求和。

原表计算步骤：1、拆解合同台账【[ERP系统] 开放采购订单号】为一合同一PAC； 2、匹配PAC清单并取PAC抬头【预估金额（抬头层级）】； 3、按货币折算[统一币种]并按合同汇总PAC金额； 4、比较【合同金额折[统一币种]】与【PAC合计金额_[统一币种]】； 5、合同金额<PAC合计金额则命中。

材料位置：原始问题清单第5行，C:D列。

PAC到期日晚于合同到期日

计算口径：PAC【有效期结束】>合同台账【当前到期日期】。

原表计算步骤：1、拆解合同台账【[ERP系统] 开放采购订单号】为一合同一PAC； 2、匹配PAC清单【采购凭证 / 采购单据】； 3、取PAC【有效期结束】与合同【当前到期日期】逐PAC比较； 4、PAC晚于合同则命中； 5、合同层面可另汇总为全部PAC晚于、部分PAC晚于、无PAC晚于。

材料位置：原始问题清单第6行，C:D列。

合同、PAC供应商不一致

计算口径：合同台账【债权人】解析出的合同供应商号，与PAC清单【供应商 / 供货中心】解析出的PAC供应商号不一致。

原表计算步骤：1、拆解合同台账【[ERP系统] 开放采购订单号】为一合同一PAC； 2、匹配PAC清单【采购凭证 / 采购单据】； 3、合同侧从【债权人】取供应商号；PAC侧从【供应商 / 供货中心】取开头供应商号； 4、两侧供应商号不一致则命中。

材料位置：原始问题清单第7行，C:D列。

一份合同对应多个PAC

计算口径：合同台账【[ERP系统] 开放采购订单号】解析出的有效PAC代码数量>=2。

原表计算步骤：1、从合同台账【[ERP系统] 开放采购订单号】解析7-12位数字PAC号； 2、对同一合同去重统计有效PAC号数量； 3、有效PAC号数量>=2则命中； 4、可同时输出PAC匹配结果：全部匹配、部分匹配、全部未匹配、无有效PAC号。

材料位置：原始问题清单第8行，C:D列。

超额度或剩余额度计算异常

计算口径：PAC抬头层级：【交货订单申请金额】>【预估金额（抬头层级）】，或【未清总金额 / 待结金额总计】>【预估金额（抬头层级）】，或【预估金额（抬头层级）】<=0但仍有下单/未清金额，或三列金额存在负数。

原表计算步骤：1、按PAC【采购凭证 / 采购单据】汇总为PAC抬头层级； 2、同一PAC多行项目只在首行计数； 3、分别判断申请金额超预估、未清金额超预估、预估<=0仍有金额、负金额； 4、任一条件满足则命中。

材料位置：原始问题清单第9行，C:D列。

过期、关闭PAC仍发生采购

计算口径：PAC抬头【有效期结束】<2026-09-09，且（【未清总金额 / 待结金额总计】>0或【交货订单申请金额】>0）；或PAC抬头【释放标识 / 审批标识】=E，且上述任一金额>0。

原表计算步骤：1、按PAC【采购凭证 / 采购单据】汇总为PAC抬头层级； 2、判断【有效期结束】是否早于2026-09-09； 3、判断【释放标识 / 审批标识】是否为E； 4、判断【未清总金额 / 待结金额总计】或【交货订单申请金额】是否>0； 5、过期且有金额，或E关闭且有金额，则命中。

材料位置：原始问题清单第10行，C:D列。

PO早于合同签署或PAC创建

计算口径：源文件无独立PO日期；以PAC【凭证日期】早于合同【合同起始日期】或【合同申请录入日期】作为代理判定。

原表计算步骤：1、拆解合同台账【[ERP系统] 开放采购订单号】为一合同一PAC； 2、匹配PAC清单【采购凭证 / 采购单据】； 3、比较PAC【凭证日期】与合同【合同起始日期】、【合同申请录入日期】； 4、PAC凭证日期早于任一合同日期则命中； 5、该项仅为代理线索，需[ERP系统] PO凭证日期最终确认。

材料位置：原始问题清单第11行，C:D列。

大额无纸质合同PAC

计算口径：PAC抬头【采购凭证 / 采购单据】未在合同台账【[ERP系统] 开放采购订单号】解析出的备案PAC集合中，且PAC抬头【预估金额（抬头层级）】达到大额门槛：[统一币种]>=1亿、UF>=2700、USD>=10万、EUR>=9万。

原表计算步骤：1、按PAC【采购凭证 / 采购单据】汇总为PAC抬头层级； 2、拆解合同台账【[ERP系统] 开放采购订单号】形成备案PAC集合； 3、判断PAC号是否未备案； 4、按【货币】判断【预估金额（抬头层级）】是否达到对应大额门槛； 5、未备案且达到门槛则命中。

材料位置：原始问题清单第12行，C:D列。

疑似拆分PAC或拆分PO

计算口径：PAC抬头层级：同【PAC供应商号】+同【短文本_norm】在180天内创建2份及以上PAC；PO级拆分缺少PO明细数据，无法验证。

原表计算步骤：1、从PAC【供应商 / 供货中心】解析PAC供应商号； 2、对PAC【短文本 / 简短描述】规范化为【短文本_norm】； 3、按PAC抬头层级用【凭证日期】排序； 4、同供应商+同短文本_norm下，任一180天窗口内PAC数量>=2，则窗口内PAC命中； 5、同一PAC多行项目只计一次。

材料位置：原始问题清单第13行，C:D列。

[ERP系统]与[合同管理系统]供应商信息不一致

计算口径：[ERP系统]供应商主数据【Nº ident.fis.1】与[合同管理系统]供应商主数据【Rut】规范化税号匹配，筛出同税号多[ERP系统]账号、单边缺失或名称规范化后不一致。

原表计算步骤：1、[ERP系统]侧生成【[ERP系统]税号_norm】=【Nº ident.fis.1】去点号/空格并大写； 2、Cert侧生成【Cert税号_norm】=【Rut】去点号/空格并大写； 3、按税号匹配[ERP系统]与Cert记录； 4、判断[ERP系统]有Cert无、Cert有[ERP系统]无、同税号多[ERP系统]账号、名称规范化后不一致； 5、任一条件满足则命中。

材料位置：原始问题清单第14行，C:D列。

未准入、冻结或注销供应商发生采购

计算口径：发生采购供应商满足：[合同管理系统]【Estatus】=Inactivo，或【Estado de Calificación】=No Apto，或[ERP系统]【[ERP系统]冻结标记】/【[ERP系统]删除标记】非0，或通过[ERP系统]税号无法匹配[合同管理系统]【Rut】。

原表计算步骤：1、从PAC【供应商 / 供货中心】解析[ERP系统]供应商号； 2、匹配[ERP系统]供应商主数据【[ERP系统]供应商号】； 3、取[ERP系统]【Nº ident.fis.1】规范化后匹配[合同管理系统]【Rut】； 4、判断Cert是否缺失、【Estatus】是否Inactivo、【Estado de Calificación】是否No Apto、[ERP系统]冻结/删除是否非0； 5、任一条件满足则命中。

材料位置：原始问题清单第15行，C:D列。

多个供应商共用银行账号、地址或联系方式

计算口径：多个供应商共用[ERP系统]供应商主数据【[ERP系统]银行账号候选】、[合同管理系统]【Dirección】、联系人邮箱或联系人电话。

原表计算步骤：1、[ERP系统]侧规范化【[ERP系统]银行账号候选】，统计同账号供应商数； 2、Cert侧规范化【Dirección】，统计同地址供应商数； 3、拆解Cert联系人JSON，提取邮箱和电话； 4、按邮箱/电话统计同共享值供应商数； 5、任一共享类型供应商数>=2则命中。

材料位置：原始问题清单第16行，C:D列。

临近月末、季末或年末集中创建PAC/下达PO

计算口径：PAC【凭证日期】日>=25，或3/6/9/12月且日>=20；源文件无PO下达日期。

原表计算步骤：1、按PAC抬头层级取【凭证日期】； 2、判断DAY(【凭证日期】)>=25； 3、判断MONTH(【凭证日期】)属于3/6/9/12且DAY>=20； 4、任一条件满足则命中； 5、PO下达集中需补充PO明细。

材料位置：原始问题清单第17行，C:D列。

PAC频繁调增、延期或重新启用

计算口径：PAC抬头【有效期结束】>=2027-01-01，或【释放标识 / 审批标识】=B且【交货订单申请金额】>0，或【释放标识 / 审批标识】=E且（【未清总金额 / 待结金额总计】>0或【交货订单申请金额】>0）。

原表计算步骤：1、按PAC抬头层级判断【有效期结束】是否>=2027-01-01； 2、判断【释放标识 / 审批标识】=B且【交货订单申请金额】>0； 3、判断【释放标识 / 审批标识】=E且仍有未清或申请金额； 4、任一条件满足则命中； 5、调增需变更历史，本次快照无法验证。

材料位置：原始问题清单第18行，C:D列。
